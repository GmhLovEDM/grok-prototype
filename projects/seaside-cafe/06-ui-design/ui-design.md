# 《汐湾咖啡馆》界面设计

> 状态：给 Him 的界面稿。静态页用浏览器直接打开，不用构建。
> 不改 `assets/` 里的定稿，也不改原型和剧本。游戏叠图时，人物和猫仍用立绘，不画进背景。

Figma 设计稿链接：https://www.figma.com/design/KXZRk5tEsWqTOlCoRkFkyW

依据：

- [写作规范](../01-planning/writing-style.md)：名字放在对话框左上角的名牌里，框里只有台词。旁白不挂名牌，用斜体或浅色。选项写要做的事，一条不超过十八个字，标点算在里面，界面上一样长。
- [画风](../04-art-prompts/README.md)：细腻的半写实手绘。成图 1920×1080。左右各约 10% 留给宽屏裁切。
- [Efe 的演示原型](../02-prototype/demo/README.md)：标题五项、点按继续、自动、快进、日志、存读档和设置项。这里换成能叠在定稿上的纸和木头，交互沿用那一版。

## 调子

夏日，海边，清透，温暖。纸是旧信纸的暖白，木头是「潮汐」柜台的深棕色，海是窗里那一点青，只用来标「可以点」和「正在开」。不另做一套冷灰，也不用警告红。文字落在纸上，不直接压在背景上。立绘的脸留在纸面外面，身子可以进到纸后面。

## 安全区

1920×1080 的画面，左右各 192px（10%）在宽屏手机上会被裁掉。门牌、船名、招牌不放在那里，按钮、字、名牌、弹窗也不放。

| 区域 | 桌面 1920×1080 | 手机竖屏 390×844 |
| --- | --- | --- |
| 裁切 | 左 0–192，右 1728–1920 | 不沿用这 10% |
| 重要界面 | 中间 1536px，再向内留 20px | 左右各 16px |
| 背景和立绘 | 可以铺满，裁掉的是海、墙、地面 | `cover`，锚在画面正中 |

实现：`--safe-x: 10%`。窄于 700px 时改为 `0px`。重要盒子写 `left/right: calc(var(--safe-x) + 间距)`。背景层和立绘不要套这道边。

竖屏不是把 16:9 缩小，而是重排：对话框和菜单贴底，立绘的头留在上半屏，可点高度不小于 44px。

## 对话框

对白和旁白共用一块纸，最小高度不跟着句子长短跳，避免画面抖。

| | 桌面 | 手机 |
| --- | --- | --- |
| 位置 | 左、右：`safe-x + 32px`；底 24px | 左、右、底各 12px |
| 最小高度 | 188px | 168px |
| 内边距 | 上 40，左右 36，下 36 | 上 34，左右 16，下 32 |
| 纸 | `--paper` 的 97%，上沿 3px `--wood` | 同左 |
| 正文 | 24px / 1.75 | 18px / 1.75 |

打字用逐字露出。默认 48ms 一字。设置里「慢」是 80ms，「快」是 16ms。稿子里的对白页放慢到大约 80ms 一字，方便打开文件时看见；游戏用 48ms。

交互：

1. 打字时，继续提示先不出现。
2. 打字中再点一次，或按 Enter / 空格，当前句立刻补全，然后才露出「点击继续」。
3. 句子完整之后，点纸面、按 Enter 或空格，进入下一句。
4. 自动：和快进互斥。打完后等待 `--duration-auto`，再进入下一句。再按一次关掉。打开菜单、选项、日志时先暂停，关掉之后若原来开着，再恢复。
5. 快进：句子直接显示完整，大约 80ms 后进入下一句。点屏幕或再按一次就停。和自动互斥。
6. 继续提示在纸的右下，16px，颜色 `--sea-deep`，旁边一个向下的小三角，1.1 秒轻轻动一次。

### 名牌

只在有说话人时出现。旁白不渲染这块。

| | 桌面 | 手机 |
| --- | --- | --- |
| 位置 | 压在纸的上沿，高出 18px，距纸左边 28px | 高出同样，距纸左边 14px |
| 尺寸 | 高 36px，左右内边距 12 / 16 | 高 32px |
| 字 | 18px，字重 500，字距 0.12em，颜色 `--wood-dark` | 16px |
| 标记 | 名字左侧 3×14px 圆角细条，颜色 `--sea` | 同左 |

名字只写人名，不写「陆屿：」。冒号留在剧本里，不进界面。

### 旁白

无名牌。句子不斜，颜色 `--ink-soft`，左侧一条竖线。纸的上内边距可以收到 28px，最小高度仍和对白一样。稿子见 [`mock/narration.html`](mock/narration.html)，用的是第 1 天的句子和落灰的店，猫是拿铁，不挂名字。

## 选项按钮

一条选项一个按钮，整栏一样宽，文案左对齐，所以长短看起来一致。文案不超过十八个字。栏宽桌面最大约 560px，在安全区里水平居中，贴在画面下方。手机改为通栏，左右 12px。

高度：桌面 52px，手机 48px。圆角 12px。字号 16px。

| 状态 | 类 | 样子 | 交互 |
| --- | --- | --- | --- |
| 默认 | `.choice` | 纸底，`--line-strong` 描边 | 可点 |
| 悬停 | `:hover` 或 `.is-hover` | 描边改为 `--sea-deep`，纸更白，阴影浮起 | 120ms |
| 按下 | `:active` 或 `.is-pressed` | 下移 1px，底色 `#e4d3be`，描边 `--wood-dark` | 松手后进入下一句 |
| 禁用 | `:disabled` 或 `.is-disabled` | 字 `--ink-faint`，底 `--paper-2`，虚线感的淡描边，鼠标是禁止 | 点了没反应。条件没到、又不会剧透的句子用这个。会剧透的句子整条不出现 |
| 已选过 | `.is-chosen` | 底 `--sea-soft`，描边 `#7aa8ad`，右侧小字「已选过」 | 仍可再选。这是以前周目选过，不是这一屏已经点过。点过会离开这一屏 |

五态叠在 [`mock/choices.html`](mock/choices.html)。「默认 / 悬停 / 按下 / 禁用 / 已选过」这些标注带 `design-only`，只在设计稿里，游戏不要渲染。

选中一条之后关掉自动和快进，再进入对应的下一句。选项上不写好感，不写结果。

## 通用按钮

高度 48px，手机也不小于 44px。左右内边距 18px。圆角 12px。字号 16px。

| 变体 | 类 | 用在 |
| --- | --- | --- |
| 纸按钮 | `.btn` | 继续、读档、设置、菜单项、弹窗里的「留下」 |
| 主按钮 | `.btn.btn-primary` | 开始游戏、继续游戏、弹窗里往前走的那一颗（覆盖、回去） |
| 浅按钮 | `.btn.btn-ghost` | 面板上的「返回」，快捷菜单底部的「回到标题」。桌面高 36px，手机高 44px |
| 开着 | `.btn.is-on` | 自动或快进当前是开的。底 `--sea-soft`，字和图标色 `--sea-deep` |
| 禁用 | `.is-disabled` 或 `disabled` | 没有存档时的「继续」，还没解锁的「图鉴」 |

状态：默认、悬停（描边变海青）、按下（下移 1px，纸色加深）、禁用（不可点）、键盘焦点（海青环）。主按钮悬停只是木头稍亮，字保持纸色。

「图鉴」锁定时，按钮里跟一个小字「锁定」。点下去没有反应。

## 顶部菜单

读文时一直在。高 56px。条本身可以通栏，字和按钮必须落在安全区里：`.hud-inner` 的左右内边距是 `safe-x + gutter`。手机上每一个可点控件的命中区至少 44px，顶栏因此保持 56px 高，四个字钮用 `--hit-sm`（44px）。

左侧日子胶囊：

- 桌面：`第 2 天` `/ 60` `第一章` `潮汐`
- 手机：只留 `第 2 天` 和地点。`/ 60` 和章节收起，避免和四个按钮抢宽度。

右侧四个字钮，胶囊形：自动、快进、日志、菜单。桌面高 36px。手机高 44px。

| 状态 | 样子 |
| --- | --- |
| 默认 | 半透明纸，木头色描边 |
| 悬停 | 描边 `--sea-deep` |
| 按下 | 下移 1px |
| 开着 | 仅自动、快进。底 `--sea-soft`，字 `--sea-deep` |

「菜单」打开快捷菜单。「日志」打开已读对白，见下文。存档和读档不放在顶栏，避免字挤进裁切区，改到快捷菜单里。

## 快捷菜单

从顶栏「菜单」或 Esc 打开。再按 Esc、点遮罩、点「继续游戏」关闭。

桌面：宽 320px 的纸卡，贴在安全区右侧（`right: safe-x + 36px`），垂直居中。立绘略向左（`left: 44%`），脸留在卡片左边。顶栏留在遮罩之上，遮罩从顶栏下沿开始，这样还能看见自动是否开着。

手机：卡片贴底，左右 16px。立绘头顶离顶栏 10px，身子延伸到卡片后面，下缘渐隐，不在腰上截断。头留在卡片上方。

条目，自上而下：

1. 继续游戏（主按钮）
2. 存档
3. 读档
4. 自动，右侧「开」或「关」
5. 快进，右侧「开」或「关」
6. 日志
7. 设置
8. 一条细线之后：回到标题（浅按钮）

自动和快进在这里切换，和顶栏是同一个状态。打开菜单时先暂停推进。关掉之后，若自动原本是开的，继续等当前这句。

「回到标题」先确认，不直接跳。文案：「回到标题？这一段会停在自动存档。」按钮：「留下」「回去」。回去用主按钮。不使用红色。

Efe 原型里还有人物图鉴和手机。图鉴从标题进，手机是玩法画面。这两项不放进这层，卡片才不会挡到脸。

日志用同一张纸，桌面宽 520px，手机改为通栏贴底。每条上面是人名或「旁白」，下面是句子。没有记录时写「还没有对白。」底部一颗「关闭」。打开日志时暂停自动和快进。

## 存档和读档

同一页，顶上分段：存档 / 读档。稿子打开的是存档，并已经弹出覆盖确认，见 [`mock/save.html`](mock/save.html)。

纸面板桌面最宽 1080px，在安全区里居中。手机几乎铺满，四周留 10px。

手动六格，另加一格自动，排在最上面，横贯整行。以后要加格子，用同一个 `.slot` 往下排。

每一格：

| 内容 | 写法 |
| --- | --- |
| 缩略图 | 16:9，当时的背景。桌面高 72px，自动格 84px；手机高 54px |
| 游戏内日期 | `第 2 天`。这是第几天，不是现实日期 |
| 章节和地点 | `第一章 · 潮汐`。序章就写「序章」 |
| 存档时间 | 现实时间，到分钟，如 `2026-07-02 07:41` |
| 自动 | 名字旁一枚「自动」徽记 |

空格：虚线框，没有图。存档模式下第二行是「点这里记下现在」。读档模式下空格不可点，第二行改为「还没有记录」。

交互：

- 存档，点空格：直接写入，不确认。
- 存档，点已有的手动格：弹出覆盖确认。被问到的那一格描边加一圈海青。
- 自动格：玩家不能覆盖。点它时不弹窗。读档时可以读。
- 读档，点已有的格：直接读，不弹覆盖。
- 返回：回到打开这一页之前的地方。从标题来，就回标题。从菜单来，就回菜单。

覆盖确认，居中。手机改贴在底部，好让上面的自动格、已有格和至少一格空栏还看得见。

- 标题：覆盖这个存档？
- 正文：第 3 天 · 第一章 · 潮汐
- 说明：写下的时间，加上「盖掉就找不回来了。」
- 按钮：留下（纸按钮，在左）、覆盖（主按钮，在右）

点遮罩等于留下。

## 设置

基础一项一行，纸面板最宽 800px。见 [`mock/settings.html`](mock/settings.html)。

| 行 | 控件 | 玩家看见的 | 内部 |
| --- | --- | --- | --- |
| 文字速度 | 滑条，两端「慢」「快」 | 慢 / 中 / 快 | 80ms、48ms、16ms 一字。默认中，48ms |
| 自动速度 | 滑条，两端「慢」「快」 | 慢 / 稍慢 / 中 / 快 | 一句打完后的等待。默认 1600ms。范围大约 2800ms 到 800ms |
| 音乐 | 滑条，两端「关」「满」 | 0–100 | 默认 70 |
| 音效 | 滑条 | 0–100 | 默认 80 |
| 全屏 | 开关 | 开 / 关 | 默认关 |
| 语言 | 下拉 | 简体中文 | 这一版只有这一项 |

滑条已走过的一段用 `--wood`，圆钮是纸色、深木描边。桌面圆钮直径 22px，轨道 4px。手机轨道加到 8px，圆钮 28px，整条滑条的命中高度 44px。手机上标签改到滑条上面，避免 96px 的标签把滑条挤没。

「慢 / 快」和面板底部的说明用 `--fs-fine`（14px）。玩家看见的是慢和快，不看见毫秒。

手机上这些控件的命中区都不小于 44px：顶栏四个字钮、返回、回到标题、存档 / 读档切换、全屏开关、语言下拉、音量和速度滑条。

对白页是第 2 天，「潮汐」，陆屿，句子用剧本里的「啧，你别动，我来。」旁白页是第 1 天落灰的店，拿铁在纸的左侧，句子是「你把靠墙的桌子擦到能看见木纹。」

背景和立绘都引用 `assets/` 里的定稿，用相对路径，不复制一份。

## 层

从下到上：背景、立绘、对话框或选项、顶栏、遮罩、弹窗或快捷菜单。快捷菜单打开时，顶栏留在遮罩上面。对话框的纸盖住立绘的下半身，不盖脸。手机上立绘头顶离顶栏 10px，下半截伸进对话框或菜单卡片后面，并用渐隐收边，避免在大腿或腰上出现一条硬边。

## 给开发

- 颜色、字号、圆角、阴影、间距、时长都用 `tokens.css` 的变量，不要在组件里再写一套色值。
- 组件类在 `ui.css`：`.dialogue`、`.nameplate`、`.line`、`.continue`、`.choice`、`.btn`、`.hud`、`.slot`、`.modal`、`.quick-card`、`.set-row`。
- `design-only` 的状态标注不要做进游戏。
- 悬停在真机上可以不出现，按下和禁用必须在。
- 打包 Electron / Capacitor 时，桌面按 1920×1080 的安全区排，手机竖屏走 700px 以下的那一套。宽屏手机若是把 16:9 左右裁掉，裁的是背景，不是按钮。
- 手机可点区域至少 44px。`--sea` 和 `--sunset` 只做装饰，纸上的字用 `--ink`、`--ink-soft`、`--wood-dark`，短提示可以用压暗后的 `--sea-deep`。
- 思源黑体子集和 OFL 全文放在 `mock/fonts/`。
