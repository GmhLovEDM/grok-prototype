# 可攻略角色

一位可攻略角色一个文件。文件名是姓名的拼音：小写，按字断开，用连字符连接。例如夏栀写成 `xia-zhi.md`。正文用中文，一级标题写角色名。

每个人物小传包含：可攻略对象、身份、性格、个人线。这些是策划初稿，和 [需求](../../00-requirements/requirements.md) 冲突时以需求为准。

不可攻略的人物先不放这里。
