# 《汐湾咖啡馆》演示原型

灰盒可点击原型，用来看这一版演示的界面和点击路径。不是最终美术，也不是完整的六十天。

## 怎么打开

不需要安装，也不需要构建。用浏览器直接打开文件即可。

- 游戏：[`index.html`](index.html)
- 流程总览：[`overview.html`](overview.html)

建议用 Chrome、Edge 或 Firefox。桌面窗口会收成 16:9，窄屏（手机）会铺满竖屏。

总览页上的每张卡片都能点进对应画面。地址栏带 `#` 的链接只用于跳到那一屏，例如 `index.html#phone`。

## 主路径

1. 标题：开始游戏、继续、读档、设置。图鉴是锁着的。
2. 新游戏：选男主或女主，写一个名字。
3. 对话：序章回到汐湾，第 2 天遇见陆屿。点击文本继续，也可以开自动或快进。
4. 分支：三句回应。有的选择会闪一下心，没有数字。
5. 日程 · 白天：第 3 天 / 60，先做咖啡馆班次。
6. 手冲：温杯、闷蒸、注水。可以跳过，跳过按普通表现结算。
7. 日程 · 傍晚：班次做完后，去码头、灯塔、礁石滩或老街其中一处。邮局和卫生所还锁着。
8. 手机：沈若的消息。她本人还没到汐湾。
9. 章末：演示直接快进到第 14 天。
10. 结局示意：按主角性别各放一张固定卡片。

菜单里可以打开日志、存档、读档、人物图鉴、手机和设置。设置从标题也能进。

## 哪些是占位

- 背景和人物都是灰盒剪影，不是立绘。
- 大纲里写过的句子用了原文，例如外婆的信、陆屿的「啧，你别动，我来」、夏栀的「你回来了，这家店就还在」、沈若的「听说你辞职了？」、前公司的「位置给你留着，八月底前答复」。旁边没有原文的对白，是按人设补的占位。
- 第 4 天到第 13 天没有演出。章末是快进过去的示意。
- 结局不按游玩结果计算。男主固定看夏栀那张，女主固定看陆屿那张。
- 亲近程度不显示数字。图鉴里只有心和一句关系。
- 语言开关只有简体中文真正在用。繁体和英文会提示这份演示还没翻译。
- 音量只影响点击时的一声轻音。
- 手冲的节奏条是示意，跳过就是普通表现。

## 这一版故意没做完的事

登场仍按大纲：演示里能见到陆屿、夏栀，沈若只在消息里。唐棠、许之言、叶帆以及第二章的人在图鉴里锁着。拉花和配方猜谜不在这版演示里。
