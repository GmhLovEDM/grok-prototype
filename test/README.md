# 拾光 · 登录注册原型

这是一个可点击的手机端登录 / 注册流程原型。页面使用原生 HTML、CSS 和 JavaScript，不需要安装依赖，也不需要构建。

## 如何打开

用浏览器直接打开 `test/index.html` 即可。桌面宽度下，界面会居中显示在手机外框里；窄屏下按约 390px 的手机宽度排布。

如果希望本地存储（登录状态、「记住我」）在各页面之间更稳定，可以在仓库根目录起一个静态服务：

```bash
python3 -m http.server 8080
```

然后访问 [http://localhost:8080/test/index.html](http://localhost:8080/test/index.html)。

## 点击路径

1. 在入口页点击「登录」，进入登录页。
2. 登录页点击「立即注册」。
3. 输入 11 位中国大陆手机号，点击「获取验证码」。按钮会进入 60 秒倒计时。
4. 验证码填写任意 6 位数字，设置密码并再次确认，勾选同意《用户协议》和《隐私政策》。
5. 点击「注册并登录」。按钮会短暂显示加载，随后进入已登录首页。
6. 首页点击「退出登录」，登录状态被清除，回到登录页。未登录时直接打开首页也会跳回登录页。

也可以停在登录页：输入手机号或邮箱和密码，勾选「记住我」后登录。下次打开登录页会预填账号。密码框旁的「显示 / 隐藏」可切换明文。

「忘记密码？」进入重置页：验证账号、获取验证码、设置新密码。成功后回到登录页，并提示使用新密码登录。

微信登录和「通过 Apple 登录」只展示样式。点击后会出现提示，不会建立登录状态。

## 校验说明

提交时会在字段下方显示错误，例如空账号、手机号或邮箱格式不对、密码不足 8 位或缺少字母与数字、两次密码不一致、未获取验证码、未勾选协议。修正输入后，对应错误会消失。

演示环境不会请求服务器。任意 6 位数字验证码都视为有效，但必须先点击「获取验证码」。登录状态保存在浏览器 `localStorage` 的 `shiguang.session` 中。
